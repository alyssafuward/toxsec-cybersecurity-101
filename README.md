# ToxSec / cybersecurity 101: an interactive map

A click-to-reveal version of the ToxSec cybersecurity 101 poster: the CIA triad, six security areas, threat modeling in 5 questions, the OWASP Top 10 (2025) and a live-review flow.

Click a shape to open it. Keep clicking a box to reveal one line at a time, or press "all". "Show everything" and "Reset" are at the bottom.

Single static file (`index.html`), no build step.
